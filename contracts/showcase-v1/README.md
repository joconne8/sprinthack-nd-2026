# Additive showcase API

Base: `/api/showcase/v1`; every JSON response carries `contract_version: "showcase-v1"` and `synthetic: true`. Existing `/api/v1` contracts remain unchanged. `schema.json` defines strict nested requests/responses and `types.ts` is generated by `python3 contracts/build_showcase_schemas.py`.

Read-only resources: snapshots, scoped metrics, comparison, evidence, inputs, summary, sources, recipes and runs. Questions accept a pinned snapshot, scope and text and return deterministic typed tool results. Workbook, normalized CSV and data-dictionary downloads reference the same immutable snapshot.

Recording workflow: POST recordings, validated events, review and approval. Only approved source-specific recipes can start a bounded acquisition run. Run event/frame endpoints expose actual Playwright evidence. The fixed same-origin portal route allows only the two replica journeys; arbitrary destinations and executable report instructions are excluded.

Database migration 002 is additive. Snapshots pin source publication IDs, auxiliary-input versions/checksums and coverage. Amounts are integer cents; ratios use Decimal. Source/native date conventions, missing-input and platform-allocation rules are defined in the downloadable dictionary and sample README.
